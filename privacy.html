Privacy Policy

This policy explains how the GIANT AutoStudio Windows desktop application (“AutoStudio”) handles information when you use its TikTok upload feature.

1. Information handled on your computer

AutoStudio stores TikTok authorization tokens and the TikTok account identifier returned during authorization in a configuration file on your computer. Generated scripts, audio, videos, and diagnostic logs are also stored locally in the application folders. AutoStudio does not operate a cloud server for these files.

2. Information sent to TikTok

When you authorize TikTok, the application exchanges an authorization code for tokens. When you start an upload, it sends the selected generated video file to TikTok Content Posting API so TikTok can place it in your inbox as a draft. TikTok processes the file under its own privacy policy. You decide whether to edit or publish the draft in TikTok.

3. Other connected providers

If enabled, Google Gemini receives prompts and narration text to generate scripts and speech. If YouTube upload is enabled, the video and its metadata are sent to YouTube using the Google account you authorize. These providers process information under their own privacy policies. AutoStudio does not sell personal information or use it for advertising.

4. Retention and deletion

Local files remain on your computer until you delete them. To remove TikTok authorization from AutoStudio, delete its local TikTok token file and revoke the app's access in your TikTok settings. Deleting a local token does not delete videos already uploaded to TikTok; manage those in TikTok.

5. Security

Keep your Windows account and application configuration private. Do not share API keys, client secrets, OAuth tokens, or token files. Anyone who obtains valid tokens may be able to use the permissions you granted.

6. Contact

For privacy questions, contact the AutoStudio developer through the support contact shown in the application's developer listing.

개인정보 처리방침

이 방침은 GIANT AutoStudio Windows 프로그램(“AutoStudio”)이 TikTok 업로드 기능을 사용할 때 정보를 처리하는 방법을 설명합니다.

1. 컴퓨터에 저장되는 정보

AutoStudio는 TikTok 인증 토큰과 인증 중 TikTok에서 받은 계정 식별자를 사용자의 컴퓨터 설정 파일에 저장합니다. 생성한 대본, 음성, 영상 및 진단 로그도 프로그램 폴더에 로컬 저장합니다. 이 파일들을 저장하는 AutoStudio 자체 클라우드 서버는 운영하지 않습니다.

2. TikTok으로 전송되는 정보

TikTok 인증 시 프로그램은 인증 코드를 토큰으로 교환합니다. 사용자가 업로드를 시작하면 생성된 영상 파일을 TikTok Content Posting API로 보내 계정 받은편지함의 초안으로 만듭니다. TikTok은 자체 개인정보 처리방침에 따라 파일을 처리합니다. 초안을 수정하거나 게시할지는 사용자가 TikTok에서 결정합니다.

3. 기타 연결 서비스

기능을 켠 경우 대본과 음성 생성을 위해 Google Gemini에 프롬프트와 내레이션 문장을 전송합니다. YouTube 업로드 기능을 켠 경우 사용자가 인증한 Google 계정으로 영상과 메타데이터를 YouTube에 전송합니다. 각 제공자는 자체 개인정보 처리방침에 따라 정보를 처리합니다. AutoStudio는 개인정보를 판매하거나 광고에 사용하지 않습니다.

4. 보관 및 삭제

로컬 파일은 사용자가 삭제할 때까지 컴퓨터에 남습니다. AutoStudio의 TikTok 인증을 제거하려면 로컬 TikTok 토큰 파일을 삭제하고 TikTok 설정에서도 앱 접근 권한을 해제하세요. 로컬 토큰을 삭제해도 이미 TikTok에 업로드된 영상은 삭제되지 않으므로 TikTok에서 관리해야 합니다.

5. 보안

Windows 계정과 프로그램 설정 파일을 안전하게 관리하세요. API 키, 클라이언트 시크릿, OAuth 토큰 및 토큰 파일을 공유하지 마세요. 유효한 토큰을 가진 사람은 허용된 권한을 사용할 수 있습니다.

6. 문의
